# Documents du colloque

Déposer ici les fichiers PDF à mettre en ligne.

## Programme

Nommer le fichier exactement :

    programme-colloque-ia-sante-2027.pdf

Puis, dans `index.html`, section « Programme », retirer les balises de
commentaire `<!--` et `-->` qui entourent le bloc `pdf-block`. Le visionneur
intégré et les deux boutons (consulter / télécharger) s'afficheront alors
automatiquement.
